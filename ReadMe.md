## 📌 1. Sobre o Projeto

O objetivo deste trabalho é consolidar os fundamentos da Web Front-End utilizando marcas semânticas em HTML5, estilização com CSS3, organização de layout com Flexbox e versionamento de código[cite: 4].

### Estrutura de Páginas e Diretórios:
- `index.html`: Página inicial contendo o cabeçalho principal, tópicos de estudo sobre desenvolvimento web e navegação[cite: 4].
- `sobre.html`: Apresentação acadêmica e profissional de **Rafael de Oliveira Anjos**, detalhando histórico de formação básica, cursos técnicos, graduação na FATEC e atuação na empresa **Rafinha Tecnologia**[cite: 4].
- `contato.html`: Canal direto de comunicação contendo hiperlinks para redes profissionais (LinkedIn, GitHub, Linktree, Instagram, WhatsApp) e um formulário funcional para envio de mensagens[cite: 4].
- `static/css/estilo.css`: Folha de estilo centralizada que aplica regras de reset global, diagramação de layout via Flexbox e efeitos interativos de transição de cores (`:hover`) nos links de navegação.
- `static/imagens/logo.png`: Diretório de recursos visuais contendo a logomarca oficial da Rafinha Tecnologia.

| Tecnologia / Conceito | Descrição |
| :--- | :--- |
| **HTML5 Semântico** | Estruturação com uso de tags `<header>`, `<nav>`, `<main>`, `<section>` e `<footer>`[cite: 4] |
| **CSS3 & Flexbox** | Estilização externa organizada em diretórios, reset de propriedades e alinhamento flexível de elementos[cite: 4] |
| **Formulários Web** | Campos de entrada (`input`, `textarea`) com validação nativa (`required`) e rotulagem (`label`)[cite: 4] |
| **Git & GitHub** | Controle de versões por meio de commits estruturados[cite: 4] |
| **GitHub Pages** | Hospedagem estática e publicação contínua do projeto na Web[cite: 4] |
